Step 1 · File structure

How the file is laid out

An EPW is plain text. The first eight lines each start with a keyword and describe the site. Everything after line 8 is the data, one line per hour, usually 8,760 lines. Select a line to see how it splits on commas.

Step 3 · The 35 hourly fields

Field dictionary

Step 5 · A single record

Read one line of data

Pick a date and hour; every file shows its record for that moment. EPW hours run 1 to 24, and hour 1 covers midnight to 1:00. Missing values are flagged.

Advanced · File as a tree

Structure explorer

The whole file as nested data, the way an editor shows JSON. Header lines become named objects; the hourly block is grouped month, then day, then record, then field. Branches load when opened. Select a node to see its path, value and meaning.
